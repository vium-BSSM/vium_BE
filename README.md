자취생·1인 가구의 식재료 낭비를 줄이기 위한 서비스 PickDo(비움)의 백엔드 API.

## 커밋 컨벤션

```
type: 설명
```

| type | 의미 |
|---|--|
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `refactor` | 동작 변화 없는 코드 구조 개선 |
| `docs` | 문서 수정 (README, CLAUDE.md 등) |
| `test` | 테스트 코드 추가/수정 |
| `chore` | 빌드/설정/의존성 등 기능과 무관한 변경 |
| `style` | 포맷팅 등 로직에 영향 없는 변경 |
| `rename` | 파일/폴더명 변경 |
| `remove` | 파일/코드 삭제 |
